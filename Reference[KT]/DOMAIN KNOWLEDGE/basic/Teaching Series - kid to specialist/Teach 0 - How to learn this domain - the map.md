# Teach 0 - How to learn this domain - the map

This series teaches you the Centum RFQ/CAM domain from zero to specialist, using the real files. It builds on the 5 reference docs (Domain 0-4) in this folder - those are the encyclopedia, these are the lessons.

## The one-paragraph version of everything

A customer sends Centum a Bill of Materials (BOM) - a list of every electronic part in a product they want built. Centum must price thousands of parts, from dozens of suppliers, in several currencies, across multiple product variants and volumes, without mistakes. That pricing exercise is the RFQ (Request for Quotation). Today humans run it in Excel + a quoting tool called QuoteWin, and it takes days. CAM (Centum Automation Modules) is the software being built to do it in hours. The giant workbook "CAM - Sample BOM.xlsx" is the best record of what the whole computation actually is.

## How to study

- Each lesson ends with a "check yourself" section. Do it in the real files, not in your head.
- Everything marked REAL comes from the actual project files (mostly the CE-005405 sample workbook). Nothing is made up.
- When a lesson uses a term you forgot, the full glossary is in Domain 1. When you want the exact structure of a file, that is Domain 3. The deep formula reference is Domain 4.
- Rule from the source material itself: never trust a number you cannot trace to a source. That is how the professionals on this project work, and it is the habit this series trains.
